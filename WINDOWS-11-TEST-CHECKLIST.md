# RC20: Windows 11 test checklist

UNSIGNED TEST PREVIEW. Non-production only. Mac-assembled with unchanged verified Windows Node runtime bytes. Not a native installer or Microsoft Store release. Do not disable Windows or organizational controls to run it.

1. Save and close the previous FUSE window and console. Extract the entire RC20 ZIP into a new folder and start **Start FUSE.cmd**. Keep the Windows user's FUSE application-data folder; existing RC19 queries/connections should remain. Do not report a policy block as a pass.
2. Open **Settings**. Review General, SQL files, Coding tools, Privacy & about and Keyboard shortcuts. Check the top and bottom of every section at your normal Windows scaling. Expect consistent padding, aligned controls and no clipped text or empty half-width card rows.
3. Use Tab, Shift+Tab, Enter and Space. Focus must remain visible, inactive category controls must not receive focus, and Reduce motion should turn on/off by keyboard. Change the default row count and restart: the preference should remain.
4. Under **SQL files**, edit the save location, switch to another settings category, then return: the unfinished edit should remain. Discard change restores the saved location. Use this folder must acknowledge a valid absolute path or show an error without pretending it saved. Save an actual query and verify its SQL file. Restore your preferred folder afterward.
5. Under **Coding tools**, choose Codex, Claude Code or Other MCP client. Copy the configuration; preserve existing client settings and update the old FUSE entry rather than duplicate it. Review Windows config-file help and manual stdio fields as needed. Never paste secrets into the setup or share machine-specific config publicly.
6. Reconnect the external client, then use **Copy test prompt**. Expect a FUSE schema tool call for PER_ALL_PEOPLE_F, with no query execution. A copied snippet alone is not a connection test. If a client has independent file access, keep it away from FUSE data/exports.
7. Optional MCP actions must begin off each session. Enable creation only if needed, approve a synthetic query/folder request inside FUSE and verify it is saved. Execution is separate: use only an authorized non-production connection, review each request, and verify result rows remain in FUSE while the agent gets only status/counts. Restart and confirm both permissions reset off.
8. Check Privacy & about: history remains optional; clearing it requests confirmation and preserves queries/drafts. Read the Oracle independence and preview limitations. In Keyboard shortcuts, verify the Windows Ctrl labels.
9. Regression-check RC19 functionality: connection preparation under `/Custom/FUSE` with extensionless visible object names; password/query persistence after restart; the original 100-row SELECT-star request; bare-column insertion versus alias-dot completion; nested SQL imports/pins; alphabetical schema browsing and official documentation links. Do not clean old Oracle catalog objects without administrator approval.

Reply with Windows build, display scaling, browser version, package SHA-256 and Pass / Fail / Blocked / Not tested for each item. For visual issues, a screenshot of Settings without tenant data is helpful. Exclude credentials, tenant URLs, sensitive SQL literals and result rows.
