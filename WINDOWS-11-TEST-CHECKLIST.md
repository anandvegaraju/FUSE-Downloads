# RC21: Windows 11 test checklist

UNSIGNED TEST PREVIEW. Windows 11 x64. Non-production only. Mac-assembled with unchanged verified Windows Node runtime bytes. Not a native installer or Microsoft Store release. Do not disable Windows or organizational security controls.

1. Save and close the previous FUSE window and console. Extract the whole RC21 ZIP to a new writable folder, start **Start FUSE.cmd** and keep its console open. Preserve the Windows user's existing FUSE application-data folder. Confirm your saved connections, queries and drafts remain after a restart.
2. At your normal Windows display scaling, review both a wide window and a narrower one (at least 960 pixels). Open the Query Library: connection, row count, hard cap, Run, Format, Save and Save as must remain reachable. Run a safe non-production query; review results, resizing and CSV export.
3. Open **Settings** and scroll through every category, including the bottom of Coding tools and Privacy & about. Expect consistent padding and no clipped controls. Switching category should return to the top. An unfinished SQL-folder edit must survive switching away/back; Discard change must restore the saved folder.
4. In **Schema**, select PER_ALL_PEOPLE_F. Check descriptions, full primary key, official documentation link and narrow-window column layout. Scroll down, search/clear columns, then select a different object: its detail starts at the top and the table list stays alphabetical. Expand/collapse a long object description if available.
5. In **Relationships**, compare paths and scroll to the lower join evidence, sources, warnings and SQL preview. Full table names and the complete path should remain readable. Insertion still requires acknowledging the review checkbox. Review effective-date, language and business-grain predicates before using generated SQL.
6. In the library, expand **Import SQL files**, import a harmless nested SQL folder, pin a query/folder and filter/search. Save a new query and check its actual `.sql` file in Documents/FUSE/Queries or your chosen folder. Original imported/external files must not be overwritten.
7. Use Tab, Shift+Tab, Enter and Space through controls/dialogs. Library action menus and focus should be visible with the keyboard. Open Commands, use arrow keys to its final result, and Escape to close. Verify Windows Ctrl shortcut labels. Review the connection dialog's lower/advanced section without changing real credentials unnecessarily.
8. For optional MCP, copy fresh setup from **Settings > Coding tools**, update the existing FUSE entry (preserving other client settings), reconnect and use **Copy test prompt**. Expect an actual schema tool call, not an answer from memory. Machine-specific config should not be posted publicly.
9. Creation/execution permissions must begin off each session. If testing creation, enable it, request a harmless SQL file/folder, approve inside FUSE and verify the saved file. Execution is separate and only for an authorized non-production connection; results stay in FUSE and the agent receives status/counts only. Restart and confirm permissions reset off. A denied request must not execute.
10. Regression-check connection preparation under `/Custom/FUSE`, extensionless visible XDM/XDO object names, saved passwords, your original 100-row SELECT-star query, bare-column insertion and alias-dot completion. Do not delete older tenant catalog objects without administrator approval.

Reply with **Pass / Fail / Blocked / Not tested**, Windows build, display scaling, browser version and ZIP SHA-256. For visual defects, attach a redacted screenshot showing the relevant full window and where you scrolled. Exclude credentials, tenant URLs, sensitive SQL literals and result rows. A security-policy block is not a pass and must not be bypassed.
